How it works

Every EU public buyer above the EU thresholds must publish on TED, the official journal. We read TED every day, keep the notices that are still open, clean them up and translate the titles to English. For alerts and full exports we run the same search for you on Apify: filter by keyword in any language, country, CPV code, value and deadline, and get a spreadsheet, JSON or API feed.
