Alerts and API

The list on this site is free. If you want the tenders that match your business delivered every morning, or the full data as a spreadsheet or API feed, use our tender finder on Apify.

What you set up once

Keywords in any language (for example rengøring, städning or cloud), the countries you sell to, CPV codes if you use them, and a minimum contract value if small jobs are not worth your time. Then add a daily schedule in Apify.

What you get each morning

Only the notices that are new since the last run, one row per tender: title, buyer, buyer email, deadline, estimated value, CPV codes, the place of performance and links to the TED notice and the tender documents. Apify can send them to email, Slack, Google Sheets or your CRM.

Coverage

All notices on TED, which covers contracts above the EU thresholds from every EU and EEA country. Smaller national tenders that only appear on national portals such as udbud.dk or Doffin are not included yet.
